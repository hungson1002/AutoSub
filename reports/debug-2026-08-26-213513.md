# Báo cáo chẩn đoán tiến trình tải bị đứng sau backend restart

> Thời gian: 2026-08-26 21:35
> Loại lỗi: runtime/API
> Phạm vi: batch tải Douyin/Bilibili trong chế độ `npm run dev`

## Mô tả

- Phần trăm tải dừng, terminal không có tiến triển mới.
- UI vẫn hiển thị bốn video đang tải.

## Đường tái hiện

1. Bắt đầu tải video.
2. Sửa file backend khi `tsx watch` đang chạy.
3. Backend restart, Vite tạm báo `ECONNREFUSED` rồi batch cũ trả 404.
4. UI tiếp tục giữ snapshot phần trăm cũ và polling vô hạn.

## Bằng chứng

- Terminal ghi `change in ./server/services/douyinDownloader.ts Restarting...` đúng lúc tiến trình dừng.
- Batch job và AbortController hiện lưu trong RAM nên biến mất khi Node restart.
- Polling cũ chỉ thử lại mọi lỗi, không xử lý riêng 404.

## Giả thuyết và xác minh

| Giả thuyết | Cách xác minh | Kết quả |
| --- | --- | --- |
| CDN tải chậm | So sánh thời điểm đứng với log restart | Bác bỏ |
| Backend restart làm mất batch trong RAM | Kiểm tra nơi lưu batch và log 404/ECONNREFUSED | Xác nhận |
| UI giữ trạng thái cũ vì 404 bị retry như lỗi mạng | Kiểm tra catch của polling | Xác nhận |

## Nguyên nhân gốc

Hot reload backend chấm dứt tiến trình đang tải và xóa Map chứa batch. Frontend không phân biệt batch mất với lỗi mạng tạm thời.

## Nội dung sửa

- Nhận biết phản hồi 404 khi polling batch.
- Tự lấy các URL đang chờ/đang tải từ snapshot và tạo batch thay thế.
- Nếu tạo lại thất bại, dừng trạng thái giả và đưa link về ô nhập.

## Kết quả xác minh

- `npx tsc -b --pretty false` đạt.

## Rủi ro còn lại

- Dữ liệu tải dở của tiến trình đã chết không thể tiếp tục và phải tải lại từ đầu.
- Mỗi lần chỉnh file backend trong dev vẫn gây restart; không sửa backend trong lúc tải dài sẽ tránh gián đoạn.

## Bước tiếp theo

Giữ terminal chạy và tránh lưu file trong thư mục `server` khi đang tải video dài.
